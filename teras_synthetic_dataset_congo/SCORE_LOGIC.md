# Score Logic

## Principes

Le score TERAS ne doit pas etre deduit uniquement des profils initiaux.
Il doit etre explicable a partir des documents fournis.

## Dimensions ciblees - Utilisateurs

- identite verifiable
- coherence adresse / domicile
- regularite des revenus
- regularite des flux bancaires
- niveau de charges apparent
- qualite documentaire
- anciennete professionnelle approximative
- niveau apparent d'endettement

## Dimensions ciblees - Entreprises

- formalisation administrative
- coherence activite / flux
- densite documentaire
- structure ventes / achats
- regularite bancaire
- tension de tresorerie
- saisonnalite
- risque operationnel apparent

## Sortie attendue

Pour chaque profil :

- score numerique
- bande attendue
- niveau de risque
- facteurs positifs
- facteurs de vigilance
- completude documentaire
